Open source time tracker

Naptimer

A cross-platform desktop time tracker written in C with NAppGUI. Ported from gtimer, with all app data stored as CouchDB-ready JSON documents in SQLite.

C / NAppGUI SQLite docs CouchDB-ready GPL-2.0-or-later

What it does

  • Track time by task with daily totals and running timers.
  • Organize work with projects, tags, and annotations.
  • Navigate by day and review totals for selected dates.
  • Generate text or HTML reports with date ranges and rounding.
  • Use quick entry: task@project #tag.
  • Export/import data and back up the local database.

Port goals

Naptimer keeps gtimer's daily-total tracking model, but replaces GTK/Libadwaita with NAppGUI for a lightweight cross-platform desktop UI.

Instead of relational app tables, every persisted object is stored as a JSON document in a single SQLite table. This keeps local storage simple and makes future CouchDB synchronization straightforward.

Data model

All application data lives in one table. The doc column contains JSON with a type field; _rev uses CouchDB-style N-hash revisions.

CREATE TABLE IF NOT EXISTS docs (
  id    TEXT PRIMARY KEY NOT NULL,
  _rev  TEXT NOT NULL,
  doc   TEXT NOT NULL
);

Document IDs include settings, session, project-N, task-N, day-N-YYYY-MM-DD, annotation-N, and tag-N.

Build

NAppGUI SDK must be installed (default /usr/local/nappgui). SQLite3 development files are required.

./build.sh

# or manually
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX=/usr/local/nappgui
cmake --build build

CLI

Naptimer includes a command-line interface for scripting and quick checks.

naptimer --list-tasks
naptimer --start 1
naptimer --stop
naptimer --report weekly --report-file report.txt
naptimer --export-json export.json

Features

  • Projects, tasks, tags, annotations
  • Start/stop/toggle, stop-all, auto-save
  • Day navigation and daily totals
  • Text and HTML reports
  • JSON/CSV export and CSV import
  • SQLite backup and restore
  • Portable idle detection
  • CLI for automation and status
